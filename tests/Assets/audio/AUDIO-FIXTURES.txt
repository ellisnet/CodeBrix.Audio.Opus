tests/Assets/audio - generated audio test fixtures
==============================================================================

These files are NOT third-party audio. Every one is synthesized (sine tones,
a frequency sweep) and encoded locally by tools/make_test_fixtures/make_fixtures.sh.
Re-run that script to regenerate them.

Encoder      : ffmpeg version 7.1.5-0+deb13u1 Copyright (c) 2000-2026 the FFmpeg developers

WHAT EACH FIXTURE IS FOR
------------------------------------------------------------------------------
  opus-tone-stereo-48000.opus      the everyday stereo case
  opus-tone-mono-from-16000.opus   encoded FROM 16 kHz, so the header DECLARES
                                   16000 while the stream DECODES at 48000. The
                                   voice-note shape, and the one fixture that
                                   catches a decoder trusting the declared rate
  opus-sweep-stereo-48000.opus     2 s sweep, instantaneous frequency 200 + 1800*t
                                   frequency identifies the position, so seeks can
                                   be verified from the audio itself
  opus-truncated.opus              truncated stream; must fail cleanly
  vorbis-tone-stereo-44100.ogg     NOT Opus. Every Ogg stream is stamped with the
                                   format id "ogg", so the Opus factory is offered
                                   this and must DECLINE it
  *.ffmpeg.wav                     ffmpeg's own decode of the matching .opus. Opus
                                   is lossy, so the decoder is checked against a
                                   second independent implementation within a
                                   tolerance, rather than byte-for-byte
